
# User Access Snapshot Tool

A tool that snapshots a user's access to Profiles, Permission Sets, Object and Field Access in Salesforce, all exportable for easy troubleshooting and audits.

## Features
- Snap user's Profile and Permission Sets
- Export user object and field access details
- Helps with SOX audits and access troubleshooting
